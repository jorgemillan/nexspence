Nexspence has been deployed!

1. Get the application URL:
{{- if eq .Values.exposure.type "ingress" }}
  http{{ if .Values.exposure.ingress.tls }}s{{ end }}://{{ (index .Values.exposure.hosts 0).host }}
{{- else if eq .Values.exposure.type "istioGateway" }}
  Check the Istio Gateway external IP:
  kubectl get svc -n istio-system istio-ingressgateway
{{- else if eq .Values.exposure.type "ciliumGateway" }}
  Check the cilium Gateway external IP:
  kubectl get gateway {{ include "nexspence.fullname" . }}-cilium -n {{ .Release.Namespace }}
{{- else }}
  kubectl port-forward svc/{{ include "nexspence.fullname" . }} 8081:{{ .Values.service.port }}
  http://localhost:8081
{{- end }}

2. Default credentials: admin / admin123 (change immediately!)

3. To upgrade:
   helm upgrade {{ .Release.Name }} nexspence/nexspence -f your-values.yaml
